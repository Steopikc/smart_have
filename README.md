
# smart_haveЦИФРОВОЙ УЛЕЙ — СБОРКА С ПОДКЛЮЧЕНИЕМ ИИ К ЗАГРУЖАЕМОЙ БАЗЕ

СОСТАВ ПАПКИ
- app.py          графический интерфейс
- data_io.py      проверка/импорт SQLite, CSV/JSON и COM/USB телеметрии
- ai_connector.py чтение данных из активной БД и подключение языковой модели
- requirements.txt зависимости Python
- start.bat       установка зависимостей и запуск в Windows

ЗАПУСК В WINDOWS
1. Установите Python 3.10 или новее и отметьте Add Python to PATH.
2. Распакуйте весь архив в одну папку.
3. Дважды нажмите start.bat. При первом запуске он установит зависимости.
4. Запустите LM Studio, загрузите подходящую языковую модель.
5. В LM Studio включите Local Server. По умолчанию приложение обращается к
   http://localhost:1234/v1.
6. В приложении нажмите «Импорт базы» и выберите файл SQLite (.db/.sqlite/.sqlite3)
   или SQL-скрипт (.sql). Для замены выберите «Заменить текущую базу».

КАКАЯ СХЕМА БД НУЖНА
Обязательные таблицы:
- apiaries: apiary_id, name
- hives: hive_id, apiary_id, hive_code
- hive_sensor_logs: hive_id, record_date

Дополнительные измерения (если есть) автоматически попадут в контекст ИИ:
internal_temp_c, internal_humidity_pct, co2_ppm, hive_weight_kg,
daily_weight_delta_kg, lid_opened_count, lid_event_cause, is_tipped_over,
tipping_cause, sound_level_db, bee_activity_index, estimated_flights_count,
ambient_temp_c, anomaly_flag, anomaly_description.
Дополнительно поддерживается таблица daily_weather.

КАК ИИ ПОЛУЧАЕТ ДАННЫЕ
При каждом сообщении приложение заново формирует контекст из текущего SQLite-соединения:
сводные показатели, количество пасек/ульев/записей, выбранный период, список ульев,
последние измерения и аномалии. При импорте базы приложение переподключается к новой БД
и очищает историю чата, чтобы не смешивать сведения из разных баз.
Для анализа конкретного старого периода выберите его в разделе «Аналитика и графики»
(кнопка «Период»), затем задайте вопрос ИИ.

НАСТРОЙКА ДРУГОГО СЕРВЕРА ИЛИ МОДЕЛИ
Можно задать переменные среды:
DIGITAL_HIVE_LLM_BASE_URL  например http://localhost:1234/v1
DIGITAL_HIVE_LLM_MODEL     идентификатор модели
DIGITAL_HIVE_LLM_API_KEY   API-ключ сервера
DIGITAL_HIVE_LLM_TIMEOUT  таймаут в секундах (по умолчанию 180)

ВАЖНО
- ИИ доступен только когда запущен совместимый с OpenAI API сервер модели.
- Проверка базы подтверждает структуру и целостность SQLite, но не гарантирует
  корректность самих измерений или единиц измерения.
- Перед заменой рабочей базы сохраните резервную копию исходного файла.
